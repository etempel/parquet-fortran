# Compile footprints of this library's advertised entry modules.
#
# One section per module, holding the sorted list of THIS LIBRARY's source files that fpm
# compiles into a downstream project whose only import is `use <module>`. Generated and checked
# by tools/check_module_footprints.sh --  read that script's header before changing anything here.
#
# Two things to know when reading a section:
#
#   * parquet_wrapper.cpp appears in EVERY section, and always will. `link` is a package-level key
#     in fpm.toml and fpm cannot prune a C++ translation unit, so importing any single module
#     still compiles the wrapper and still links -larrow -larrow_compute -lparquet. What the
#     Arrow-free tiers guarantee is narrower and is about the FORTRAN graph: no module in it
#     imports parquet_bindings. That half is enforced separately, by
#     check_parquet_*_stays_arrow_free in tools/check_source_conventions.py.
#   * A submodule is never pruned separately from the module it belongs to, so every section is a
#     union of whole modules. That is why parquet_sorting costs 22 Fortran files rather than the
#     handful its callers touch, and why moving one procedure between two modules can move a
#     dozen files between two sections.
#
# The set of sections is the entry-module table in doc/pages/operating/choosing-a-module.md,
# which is the single authority for what counts as an advertised entry module. Adding a row
# there means adding it to this file's generator list (ENTRY_MODULES in
# tools/check_module_footprints.sh) and regenerating with --print.
#
# Only lines inside a [section] are data; anything above the first section is a comment.
